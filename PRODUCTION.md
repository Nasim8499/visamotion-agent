# VisaMOTion Production Rebuild - Original UI inspired by modern AI workspaces (use.ai-style layout pattern) + original VisaMOTion sections. Modes: Manual Chat = chat only, never starts browser. Gemini via Settings key or server GEMINI_API_KEY. AI Agent Chat = real browser job + Live Preview panel (current URL, iframe/live URL when provider returns it, timestamped step stream, stop button). Long tasks: browsers cannot stay alive in a web page or GitHub Pages. Run apps/api on your own server (VPS, Render, Railway, Fly.io, Docker host). Browser Use Cloud jobs are polled up to 15 min server-side and Playwright runs server-side Chromium. Vercel serverless is fine for Auth/AI/payments, not long Playwright jobs. Run server: cd apps/api; npm i; npx playwright install chromium (only for Playwright); set env from .env.example; psql $DATABASE_URL -f schema.sql; npm start; health check GET /health. Web/PWA: docs/ is a static installable PWA. In Settings set Production API base to your server URL. Mobile: cd apps/mobile; npm i; npx expo start. Set API constant to your server. Build store binaries with EAS (eas build) using your Apple/Google accounts. Payments: set Stripe Payment Link in app Settings for instant checkout, or STRIPE_SECRET_KEY + STRIPE_WEBHOOK_SECRET on server for /api/payments/checkout. QA checked in code: Sidebar all pages Chat, Agent, Sources, Tools, Documents, Applications, Workspaces, Payments, Account, Settings, About; mobile bottom nav Chat/Agent/Sources/Tools/Settings; mode toggle prevents browser in Manual; Agent preview starts hidden and opens on agent mode/run; all buttons wired to functions; service worker + manifest for install/offline. Live verification still requires your keys and server host because no third-party account can invent your Gemini/Browser Use/Stripe credentials or Apple/Google developer accounts.
